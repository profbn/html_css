Semana 16 — Classes, IDs e bordas

Objetivo

Diferenciar seletores de classe e ID e aplicar bordas.

Etapas: 1. Leia o exemplo. 2. Observe o resultado. 3. Faça a atividade.

Exemplo de código completo

Copie para um arquivo index.html e abra no navegador.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Semana 16</title>
  <style>
    body { font-family: Arial, sans-serif; line-height: 1.6; }
    .cartao{border:2px solid #23816b;border-radius:8px;padding:14px;margin:10px 0}#titulo{color:#0b5444}
  </style>
</head>
<body>
<h1 id='titulo'>Avisos</h1><div class='cartao'>Atividade 1</div><div class='cartao'>Atividade 2</div>
</body>
</html>

Resultado do exemplo

Imagens e mídias demonstrativas podem exigir acesso à internet ou arquivos locais.

Atividade prática

Monte três cartões usando a mesma classe.

Entrega: salve o arquivo HTML (e o CSS, quando houver), teste no navegador e envie conforme orientação do professor.
