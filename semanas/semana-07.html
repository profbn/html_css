Semana 07 — HTML5 semântico

Objetivo

Usar header, nav, main, article, aside e footer.

Etapas: 1. Leia o exemplo. 2. Observe o resultado. 3. Faça a atividade.

Exemplo de código completo

Copie para um arquivo index.html e abra no navegador.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Semana 07</title>
  <style>
    body { font-family: Arial, sans-serif; line-height: 1.6; }
    
  </style>
</head>
<body>
<header><h1>Jornal da turma</h1></header><nav><a href='#noticia'>Notícia</a></nav><main><article id='noticia'><h2>Feira de tecnologia</h2><p>Projeto da turma.</p></article><aside>Leia também: atividades.</aside></main><footer>Projeto escolar</footer>
</body>
</html>

Resultado do exemplo

Imagens e mídias demonstrativas podem exigir acesso à internet ou arquivos locais.

Atividade prática

Substitua divs genéricas por elementos semânticos adequados.

Entrega: salve o arquivo HTML (e o CSS, quando houver), teste no navegador e envie conforme orientação do professor.
