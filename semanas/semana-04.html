Semana 04 — Listas, links e agrupamentos

Objetivo

Organizar informações e criar navegação.

Etapas: 1. Leia o exemplo. 2. Observe o resultado. 3. Faça a atividade.

Exemplo de código completo

Copie para um arquivo index.html e abra no navegador.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Semana 04</title>
  <style>
    body { font-family: Arial, sans-serif; line-height: 1.6; }
    
  </style>
</head>
<body>
<nav><a href='#materiais'>Materiais</a> · <a href='#contato'>Contato</a></nav><div id='materiais'><h2>Materiais</h2><ul><li>Editor</li><li>Navegador</li></ul><ol><li>Escrever</li><li>Testar</li></ol></div><p id='contato'>Contato: <span>turma de HTML</span></p>
</body>
</html>

Resultado do exemplo

Imagens e mídias demonstrativas podem exigir acesso à internet ou arquivos locais.

Atividade prática

Monte um menu de três links e uma lista de materiais.

Entrega: salve o arquivo HTML (e o CSS, quando houver), teste no navegador e envie conforme orientação do professor.
