# Projeto final — Mostra Web 2026

## Proposta para as equipes
Criar uma **landing page original** com HTML5 e CSS3, apresentando um projeto, campanha educativa, ideia de serviço ou portfólio. O site deste diretório é **somente um modelo didático**: cada equipe deverá criar seu próprio tema e conteúdo.

## Requisitos mínimos
1. HTML5 semântico com `header`, `nav`, `main`, `section`/`article` e `footer`.
2. CSS3 em arquivo separado, sem CSS inline, `<style>` ou JavaScript embutido.
3. Navegação funcional e pelo menos quatro seções.
4. Layout responsivo com Flexbox ou CSS Grid.
5. Bom contraste, foco de teclado visível, títulos hierárquicos e `alt` em imagens informativas.
6. Conteúdo próprio da equipe, sem copiar o texto e a identidade visual do exemplo.
7. Publicação gratuita no GitHub Pages.

## Arquivos deste exemplo
```text
projeto-final/
├── index.html    # View: página HTML5
├── style.css     # Estilos externos CSS3
└── README.md     # Orientações da atividade
```
Não há backend, banco de dados nem formulários que enviem informações. O GitHub Pages publica arquivos estáticos. Para um MVC completo com backend é necessária hospedagem de servidor.

## Etapas
- **Planejamento:** tema, público-alvo, mensagem e rascunho visual.
- **Desenvolvimento:** organização semântica e apresentação em arquivos separados.
- **Validação:** verificar navegação, celular, teclado e contraste.
- **Publicação:** repositório público, Settings → Pages → Deploy from a branch → main → /(root).
